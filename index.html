What this is, and what it is not.

Everything here is honest about its own limits — the same discipline the product sells.

  • A stack we built and own. A deliberately vulnerable reference environment modelling inference, dataset ingestion, an agent runtime and a cluster.
  • Reproductions of public failure classes described in the Hugging Face and related post-mortems — recorded, deterministic fixtures.
  • Offline and self-contained. No network calls, no model, no API key. The whole thing runs from one file.
  • A proof per class: a test that fails on the vulnerable stack and passes on the contained one.
  • Not an attack on any live system, and not a scan of anyone else's infrastructure.
  • Not a newly discovered vulnerability. These are known, published classes, reconstructed — nothing here is a zero-day we are disclosing.
  • Not AI. No model is called; the "agent" steps are a scripted replay of the published sequence.
  • Not a benchmark claim. We do not assert superiority over any vendor; that needs fair, independent tests.
